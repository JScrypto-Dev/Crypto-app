# Crypto-app

Web app for crypto deposit and withdrawal.

## Backend
- **Server.js** → API endpoints: `/balance`, `/deposit`, `/withdraw`
- Run with: `node Server.js`

## Frontend
- **index.html** → main interface
- **style.css** → design
- **script.js** → connect frontend to backend

## Database
- **db.json** → store balance and transactions

## Usage
1. Start backend: `node Server.js`
2. Open `index.html` in browser
3. Use forms to deposit or withdraw
4. Balance updates automatically
